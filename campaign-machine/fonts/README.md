# פונטים לקריאייטיבים

ברירת המחדל: Arial Bold של המחשב (תומך עברית ב-Windows וב-Mac).

לפונט יפה יותר (מומלץ):
1. היכנסו ל-https://fonts.google.com/specimen/Heebo ולחצו **Get font → Download all**.
2. מתוך ה-ZIP, העתיקו את `static/Heebo-Bold.ttf` לתיקייה הזאת (`fonts/Heebo-Bold.ttf`).

פונט של מותג ספציפי: שימו את הקובץ כאן והגדירו בקובץ `config.json` של הלקוח:
`"brand": {"font": "fonts/MyBrand-Bold.ttf"}`
