# לוח תוצאות – הבחירות לכנסת ה-26

מערכת קטנה שמושכת את התוצאות מ-[votes26.bechirot.gov.il](https://votes26.bechirot.gov.il/)
ומציגה אותן בלוח בעברית שמתעדכן לבד.

## הפעלה

צריך רק Python 3, בלי התקנות נוספות.

```bash
cd elections26
python3 server.py
```

ואז פותחים בדפדפן: <http://localhost:8026>

- השרת מושך את האתר כל 60 שניות (`--interval 30` משנה את הקצב).
- הלוח בדפדפן נטען מחדש כל 30 שניות.

## מה מוצג

- **נתונים כלליים:** אחוז הצבעה, קלפיות שנספרו, קולות כשרים ופסולים, וכמה קולות דרושים כדי לעבור את אחוז החסימה.
- **חצי עיגול של הכנסת:** 120 מושבים צבועים לפי רשימה.
- **גרף מנדטים** לכל רשימה שעברה את החסימה.
- **בונה קואליציה:** בוחרים רשימות ורואים אם יש להן 61 מנדטים.
- **מגמה לאורך הספירה:** איך המנדטים השתנו בין עדכון לעדכון.
- **טבלה מלאה:** קולות, אחוזים, מנדטים ושינוי מהעדכון הקודם, עם קו שמסמן את אחוז החסימה.

## מנדטים

אם האתר מפרסם מנדטים, הלוח מציג אותם. אם לא, הם מחושבים לפי שיטת באדר-עופר
עם אחוז חסימה של 3.25%. כדי שהחישוב יהיה מדויק צריך להזין את הסכמי העודפים
ב-`config.json` לפי אותיות הרשימות, למשל:

```json
"surplus_agreements": [["מחל", "ט"], ["פה", "ל"]]
```

## אם המשיכה לא עובדת

- **כתובת העמוד:** אם התוצאות הארציות נמצאות בכתובת אחרת באתר, מעדכנים את `source.paths` ב-`config.json`.
- **חסימה:** אתרי ממשלה לפעמים חוסמים גישה מחוץ לישראל או מבוטים. כדאי להריץ ממחשב בישראל.
- **ניתוח קובץ שמור:** אפשר לשמור את עמוד התוצאות מהדפדפן ולהריץ `python3 fetcher.py --file page.html`.

## קבצים

| קובץ | תפקיד |
|---|---|
| `fetcher.py` | מושך את האתר, מזהה את טבלת התוצאות, מחשב מנדטים וכותב ל-`data/` |
| `server.py` | מריץ את המשיכה ברקע ומגיש את הלוח |
| `index.html`, `style.css`, `app.js` | הלוח עצמו, בלי ספריות חיצוניות |
| `config.json` | כתובת המקור, אחוז חסימה, הסכמי עודפים |
